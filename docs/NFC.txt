First, what is this project?

This should be written from a business perspective, not a technical one.

Portfolio Version

NFC Loyalty System is a full-stack customer loyalty platform that enables merchants to build stronger customer relationships using NFC technology and blockchain-based NFTs. Customers can check in at participating businesses using their mobile devices, earn NFT-based loyalty rewards, progress through membership tiers, and manage their loyalty history through a mobile application, while merchants and administrators manage the entire ecosystem through dedicated web dashboards.

This tells recruiters what the product is, not how it is built.

Why was it built?

This explains why the business needed the system.

Portfolio Version

Traditional loyalty programs rely on paper cards, QR codes, or manual point systems that are difficult to manage and offer limited customer engagement. The NFC Loyalty System was built to modernize customer loyalty by combining NFC-based check-ins, blockchain-powered NFT rewards, merchant management, and centralized administration into a single digital platform.

Biggest Technical Challenges

This is where your engineering ability becomes visible.

Challenge 1
Secure Wallet Authentication

The application required passwordless authentication while securely identifying blockchain users.

Solution

Integrated Privy authentication with wallet verification and backend token validation to establish secure user sessions.

Challenge 2
NFT-based Loyalty Progression

Each customer check-in could trigger NFT minting or tier upgrades.

Managing this flow while keeping application state synchronized with blockchain transactions was challenging.

Challenge 3
Multiple Applications

The project consists of

Mobile App
Merchant Dashboard
Admin Dashboard
Backend

Keeping all applications synchronized through common APIs required careful API design and consistent data models.

Challenge 4
Merchant Check-in Workflow

The system needed to

identify merchants
verify users
record check-ins
upgrade loyalty tiers
mint NFTs
update dashboards

without breaking the customer experience.

Challenge 5
Media & Metadata Management

NFT images and metadata needed to be stored efficiently.

This required integrating Cloudinary for media storage and Pinata/IPFS for decentralized metadata hosting.

Challenge 6
Deployment

The project included three independent applications.

Deploying them behind Nginx with PM2 process management while maintaining API communication and SSL configuration required production-ready deployment planning.
