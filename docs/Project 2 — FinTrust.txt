Project 2 — FinTrust

This project is significantly larger.

It is not simply a staking dApp.

What is it?

FinTrust is a full-stack decentralized staking and rewards platform built on Solana that enables users to purchase platform tokens, stake assets across configurable reward tiers, earn cashback and referral incentives, claim vested NFT-based rewards, and participate in ICO phases through a secure blockchain infrastructure backed by smart contracts and an administrative management system.

Why was it built?

Traditional staking systems usually provide only basic token locking and reward distribution.

FinTrust was designed to create a more complete token economy by combining staking, vesting, referrals, cashback, ICO participation, KYC, and administrative controls into a single platform.

What problem does it solve?

Instead of managing separate systems for token sales, staking, vesting, referral rewards, cashback programs, and compliance, FinTrust integrates these capabilities into one blockchain application with automated reward distribution and configurable tokenomics.
